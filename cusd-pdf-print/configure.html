CUSD PDF Print — Setup

The button opens a printable copy of this dashboard in a new window and prints it through the browser, so the dashboard's extensions appear — Tableau's own PDF export leaves them blank. It needs the published view's URL to know what to print.

A dashboard you are still building has not been published, so it has no URL yet — leave this blank, publish, and the first click of the PDF button will ask for the link once and remember it. If the dashboard is already published, paste the plain view URL here instead: open it on Tableau Cloud and copy the address bar. Either way the extension adds the embed and filter settings itself. Do not paste the web-editing address — leave edit mode first.
